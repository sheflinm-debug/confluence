Read this before wiring anything up

  • Signal legibility — the Info-tab dial (civ.SignalLegibility) is dead, but a Policy Catalog effect of the same name (Var.SignalLegibility) is real and fully wired, computed from State Doctrine Control / Guarded Archives selections instead. Wiring the dead dial without knowing this would create two competing sources of truth.
  • Immune caste investment — the Bio-tab dial (civ.ImmuneCasteInvest) is dead. A Policy Catalog option with the same label already drives Var.GenDMin for real.
  • Caste allocation dials vs. CasteDiff — the four Collective caste percentage sliders (Forager/Builder/Soldier/Trader) are dead. civ.CasteDiff (a separate Monomorphic/Polymorphic toggle, not a percentage) is real and drives real combat/info modifiers.
  • Military budget readout — echoes civ.SectorMilitary, which is dead. It looks like a real number because it's displayed, but nothing consumes it.

The Cobb-Douglas island

Separate from the dead-field list — this one runs, just doesn't connect to anything else.

The six-sector economy (Housing / Industry / Research / Culture / Military / Environment) is a genuinely real, self-contained simulation: Allocation is set by the Policy Sectors dials, and every tick it computes MobilizationDrag, WarWeariness, ExtractionTax, and per-sector Cobb-Douglas Output/Stock — all displayed as readouts on the Econ tab. But none of those outputs (GDP, MobilizationDrag, ExtractionTax, WarWeariness) currently feed back out into the rest of Era3Manager's war, trade, or tech formulas. It's a real engine turning in isolation. Worth deciding whether the tab-budget redesign should be the thing that finally connects it to the rest of the game.
